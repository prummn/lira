LIRA · 论文阅读与研究笔记
Windows 10 / 11，64 位

开始使用

1. 把 ZIP 完整解压到一个文件夹。不要在压缩包预览里直接双击启动。
2. 双击「启动 LIRA.cmd」，浏览器会自动打开。无需安装 Python、Node 或 npm。
3. 在文献库导入 PDF，或粘贴公开论文链接。
   暂不支持直接导入 CAJ，请先取得 PDF 版本；扫描件暂不支持 OCR。

第一次打开是空文献库。阅读、搜索、笔记和高亮可以直接使用。
翻译、分析和提问需要在「设置 → 模型连接」配置你自己的连接：
可以登录自己的 ChatGPT Codex 账号，也可以填写 API 地址、模型和 key。
包内已附官方 Codex 程序，无需另装 CLI；不包含提供者的账号或额度。
模型功能需要网络，PDF 下载同样需要能访问相应网站。

日常启动与停止

重复双击启动会打开已运行的服务，不会重复启动。
关闭浏览器后，后台分析和翻译仍会继续。要结束运行，请双击「停止 LIRA.cmd」。
端口被占用时自动换一个空闲端口，只在本机开放，不需要管理员权限。
Windows 初次运行可能要求确认脚本或允许浏览器打开本地页面。

你的数据在哪里

文献、笔记、译文、对话和账号设置均保存在：
%LOCALAPPDATA%\LIRA
可以把这行粘贴到资源管理器地址栏后回车。

数据库：paper_reader.db；原始 PDF：storage；模型连接：model.env.models.json；
官方账号：model.env.models.json.codex；服务日志：run\service.log。
这些是你的个人资料。不要把这个数据目录一起发给别人。

备份时先停止 LIRA，再复制整个数据目录。升级前也先备份，停止旧版，
然后解压并启动新版，数据会继续使用同一目录。请勿同时运行不同版本。
不要覆盖一个正在运行的程序文件夹，也不要用旧版打开已升级的数据库。

遇到问题

启动失败：查看窗口报错和数据目录下的 run\service.log。
页面断开：重新双击启动文件，通过它打开实际地址；不要固定记住端口。
模型出错：到设置检查自己的登录、模型和网络；原文及已存笔记仍保留。
这是一份同学试用版；扫描 PDF 暂不支持 OCR，复杂排版和智能回答仍需核对原文。
