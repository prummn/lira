## 日常使用

| 想做什么 | 阅读哪一篇 |
| --- | --- |
| 导入论文，开始阅读、翻译和提问 | [使用指南](USER_GUIDE.md) |
| 看清方法、数据集与论文之间的联系 | [知识摄取与网络整理](KNOWLEDGE.md) |
| 让预译、分析和专题研究在后台继续 | [后台任务与调度](BACKGROUND_TASKS.md) |
| 添加 API / Codex，切换模型或排查连接 | [模型连接](MODELS.md) |
| 分辨状态、恢复失败任务、快速查找入口 | [工作流与排错](WORKFLOWS.md) |
| 了解数据位置、外部请求与备份边界 | [安全与隐私](../SECURITY.md) |
