# 后台任务与调度

[文档目录](README.md) &nbsp;|&nbsp; [知识摄取](KNOWLEDGE.md) &nbsp;|&nbsp; [模型连接](MODELS.md)

后台任务覆盖阅读准备和专题研究。前者让已导入的论文尽早可读，后者利用可用并发整理现有知识，阅读时也会继续。任务记录保存在本机，本地服务需要持续运行；关闭浏览器与停止服务是两回事。

## 启动一项任务

| 想做的事 | 操作入口 | 查看结果 |
| --- | --- | --- |
| 多段翻译 | 阅读器 → 中英对照 → 批量翻译 | 段落状态与已完成译文 |
| 提前翻译正文 | 阅读器 → 后台预译全文 | 阅读器或后台任务中的段数进度 |
| 导入后预译与分析 | 导入确认 → 预译正文并后台分析 | 后台任务、文献库与论文卡片 |
| 核对知识网络 | 专题 → AI 知识整理 | 整理进度、对象档案与维护记录 |
| 写专题文章、找研究线索 | 专题 → 研究设置 | 专题文章、研究线索与继续研究 |

手动提交的预译无需打开可选后台研究总开关。需要自动研究时，在专题填写研究方向、选择已登录的官方连接与任务类型，再打开专题开关和后台总开关；自动知识整理还需启用对应选项。

## 三类工作怎样安排

1. **即时交互**：当前提问与手动翻译优先取得下一个可用连接位置。
2. **阅读准备**：预译在阅读器内外都可以继续，每段完成立即保存；自动导入流程先准备原文和预译，再推进全文分析。
3. **可选研究**：专题文章、研究线索和知识整理使用剩余位置，按官方额度窗口和保留线自动启动或暂停。不同专题、不同论文可以同时处理；同一专题的研究步骤按顺序推进，同一篇论文不会被多个整理批次重复检查。

阅读时，有效并发大于 1 就保留一个位置供提问和手动翻译使用。例如并发为 4，后台可持续使用其余 3 个位置；交互占用保留位置后，仍能同时运行 3 个后台请求。离开阅读并达到设置的闲置时间后，后台可借用全部 4 个位置。有效并发降为 1 时也能继续后台工作，即时交互优先取得下一个位置。

优先级作用于尚未发出的请求。已经发出的模型生成不会因为切换页面立即撤回，返回结果会先保存；取消也不意味着退还已经使用的额度。

## 额度与并发

| 控制项 | 控制什么 |
| --- | --- |
| 模型连接的并发 | 同一连接或官方账号可同时占用的本地请求位置 |
| 官方额度保留线 | 是否还有足够账号余量启动后台工作 |
| 闲置时间 | 停止阅读和交互多久后，后台可以借用全部并发位置 |

API 按连接设置调度，请求正常计费。官方账号的多个连接共享同一账户的并发与额度状态；当前本地并发默认 4，可设置为 1–8，限流后会自适应降低。这是本地上限，供应商实际支持多少由账号与服务决定。

后台不再维护本地小时调用上限，也不再根据长周期额度估算每日预算。任务启动和续跑只检查官方返回的短、长额度窗口及保留线；调用错误或供应商限流会按实际错误退避。前台交互优先取得连接位置，后台则使用剩余并发，因此某段能即时翻译时，后台仍可能正在等待前台释放连接或额度恢复。

研究设置允许选择保留线策略。可选研究只使用选择的官方连接，不会为消耗额度转用付费 API。不要把百分比变化当作单条任务的精确计费；其他客户端的账号使用也会影响官方读数。旧版本保存的小时调用次数和预算快照不会再限制新任务，仅为兼容历史数据保留。

## 等待时看哪里

左侧「后台任务」汇总预译、分析、AI 知识整理、官方额度和保留线状态。知识整理按批次显示专题或论文名称、已检查篇数、当前论文和等待原因；点击「查看整理进度」可回到对应批次。退出阅读器后仍可监视进度，已完成结果自动保存。

整理范围与本轮待检查数量分别计算。例如专题有 8 篇论文，其中 5 篇的当前版本已检查，本轮进度会显示为 0 / 3，避免重复调用模型。

| 状态或原因 | 含义与处理 |
| --- | --- |
| 等待连接 / 排队 | 可用位置被占用，当前生成完成后按优先级继续；知识整理使用剩余并发，阅读本身不会暂停整条队列 |
| 额度保留线 | 官方短、长窗口触及后台保护线；额度恢复后自动重新安排 |
| 额度查询失败 | 暂时无法读取账户状态；查看读取时间并重试查询，不等于额度耗尽 |
| 限流 / 服务退避 | 连接正在等待重试，避免持续重复请求 |
| 失败 / 部分完成 | 查看具体原因，保留已完成结果后重试剩余工作 |

## 结果怎样积累

专题文章按版本保存，支持回看、来源跳转与 Markdown 导出。研究线索可以保留、忽略或标记完成，复习题通过「再复习」与「记住了」安排后续复习。问题笔记与未完成提问也可加入继续研究。

模型提出的研究问题与验证方案是研究线索，不代表实验已经执行。后续整理会考虑已有结果与人工决定，按材料变化有限更新，允许本轮没有新线索。
