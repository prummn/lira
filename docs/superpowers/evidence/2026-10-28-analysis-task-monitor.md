# 导入后的论文分析进入后台监视器

## 原因与修复

导入 opt-in 和手动分析都会保存 IntelligenceTask，但 `/api/research/status` 只提供翻译队列和专题研究；页面与侧栏没有接入分析队列。现场确认一篇正在运行、两篇排队时汇总字段仍缺失。

- 增加只选择任务摘要列的 `monitor_analysis_tasks`，避免轮询读取完整报告/原文。所有 queued/running 保留，running 优先；历史每篇只选最新尝试，最多十篇。两次查询之间任务恰好结束时不会重复出现在活跃和历史中。
- 页面把论文分析和翻译汇总在“进行中 / 最近结束”；展示阶段、实际步骤和错误，未知总步数不显示 `0 / 0`。部分完成、失败、取消与完整成功分别显示；可取消、重试或打开论文。
- 使用现有分析操作，并重新加载文献库，处理监视器比文献库快一步发现新任务的情况；保留 useWorkspace 原有的旧响应保护。
- 侧栏纳入分析任务，专题后台研究关闭时仍显示分析状态。进入监视器立即刷新，常规汇总每五秒更新。
- 运行中的旧后端尚未提供摘要字段时，复用文献库已加载并持续轮询的任务，不增加全局完整报告轮询；不需要为显示修复而中断当前模型调用。
