# 手动额度保留线验收

新增阅读器预译队列、后台任务两个「调整保留线」入口；显示当前官方剩余额度与正在编辑的保留线。三项策略用 PATCH 局部更新，在工作器锁内合并最新设置，不覆盖其他后台选项。默认值不变；长/短窗口保留线可手动设为 0。官方额度耗尽仍拒绝后台调用。

验证结果：

- 新增后端测试先观察到路由缺失的 3 failed；修复后包含额度、翻译队列与后台研究的 104 项回归通过。
- 新增队列实测夹具验证：周额度剩余 23% 时预译受 30% 保留线拦截；PATCH 到 10% 后同一任务继续，并保存第一段，不重新建任务。
- 界面测试通过：三个字段局部提交、0 值、刷新持久化、保存失败保留草稿、520px 窗口无横向溢出。最终前端构建通过。
- 正式服务在无在途模型请求时加载；真实浏览器验证后台任务保存当前设置及阅读器 SWE-smith 队列入口。初次验证保持原 50/35/30，不擅自降低保留线。
- 随后观察到应用设置变为 50/0/0，SWE-smith 从 quota_reserve 转为 running、reason=null。这些设置保持用户当前选择。

日志和截图位于 `.local-runtime/quota-controls-*`。本轮不重新生成分发 ZIP。
