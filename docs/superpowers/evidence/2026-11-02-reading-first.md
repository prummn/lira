# 阅读优先流程验证

## 已实现

- 勾选「预译正文并后台分析」后，导入只完成本地识别并保存准备任务。后台先预译正文及图注，再开始全文分析；保留只入库与立即分析入口。
- 预译逐段保存。暂停、取消、失败不会永久阻塞分析；服务重启保留依赖和已完成译文。
- 连接按前台、手选翻译、正文预译、分析、可选研究的优先级等待。正在生成的预译先保存，不因前台活动丢弃。官方连接共用串行容量；API 按 profile 并发配置，容量大于 1 时为前台保留一个位置。
- 显式预译使用当前连接，不要求开启可选研究，也不继承其小时调用上限。官方自动生成遵守额度保留；API 不查询官方额度、不自动切换收费连接。一个连接的额度等待不阻塞独立 API 任务。
- 长论文综合保留全部事实与引用 ID，为模型提供标记为 `indexed_excerpts` 的连续原文摘录，并用 `evidence_sections` 保留每条证据的原始章节。本地完整证据、PDF 坐标和科学复核输入保持完整。事实本身仍超预算时才归纳。
- 保存时使用原文摘要校验源变化；运行中提示词版本更新不再被误报为 PDF 变化，结果保留实际生成时的版本标识。
