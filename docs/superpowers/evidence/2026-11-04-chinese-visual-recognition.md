# 中文论文公式与图表识别验证

本轮用两份真实本地文献检查识别链路：32 页双栏《SST 湍流模型改进研究综述》和 107 页毕业论文《10.论文-杨柳》。直接读取原文件，模型实验独立运行；没有向个人论文库导入测试记录，也没有更改原 PDF。

## 采用的方式

参考 [MinerU](https://github.com/opendatalab/MinerU)、[Docling](https://github.com/docling-project/docling) 对版面、公式、表格分别处理的思路，以及 [PyMuPDF 的文字与坐标提取](https://pymupdf.readthedocs.io/en/latest/recipes-text.html)。本轮没有安装或声称已集成前两者的模型。实现把区域定位、按需视觉解释和原页核对分开：定位保持轻量，复杂公式以 PDF 裁图为准，文字提取结果仍用于上下文与引用核验。

## 实际发现与修复

| 原问题 | 修复与样本 |
| --- | --- |
| 旧 Symbol 字体输出私用区字符，分子、分母与编号分别落入不同文字块 | 公式按同栏纵向几何范围组合，保留图像证据；毕业论文第 22 页 `(2-1)` 至 `(2-6)`，第 28 页多层积分与上下标 |
| 双栏公式可能在同一基线上被混合 | 依据正文分布识别栏缝；SST 第 10 页公式 `(9)`、第 20 页公式 `(16)` |
| 三线表的下边线按单元格分段绘制，只找到表头 | 先拼接共线边线，再匹配表头、分隔线、表底；毕业论文第 36、37、42、59 页 |
| 页眉长横线或图片底纹加入图像候选，图框吞入正文 | 排除页边装饰线与最大不透明度低于约 6% 的软蒙版底纹；SST 第 10、20 页 |
| 中英图注重复，图注续行漏出裁图，邻图被合并 | 按字号、紧密行距与同编号恢复双语图注；图注阻断相邻图像聚类；SST 第 20 页、毕业论文第 42 页 |
| 选区附近的公式原文被同页页眉挤出模型上下文 | 根据真实裁图坐标优先取原文块，检索同分时保留调用者顺序 |
| 视觉调用失败后降级为纯文字，仍可能被标为视觉回答 | 重试保留同一图像，最多一次；失败向上返回安全错误，保留已有对话 |

阅读器新增公式的悬浮提问入口，使用独立的 Sigma 图标。公式身份、页码与区域坐标随对话持久保存，可以从历史定位回原文。遇到私用区乱码时显示原图说明，不在摘要和历史引文中堆乱码。

## 验证范围与边界

后端相关回归 346 项通过，覆盖真实页的坐标快照、三线表全部数据行、公式编号与分式边界、双栏隔离、行内数学排除、透明底纹、完整双语图注、视觉重试保留原图、提问上下文及对话归档。浏览器 3 项通过，覆盖公式入口与历史、图表不同操作图标、表格裁图不额外扩边；使用隔离数据库和存储。前端生产构建通过，仍有既有的包体积提示。

确认正式实例没有在途研究、分析、预译和维护调用后，使用 `scripts/start.ps1 -Restart -NoBrowser` 加载修改。重启后健康检查 200，已有《Attention Is All You Need》的真实 `visual-regions` 接口返回 200，包含 5 个图、5 个表和 7 个公式候选。未触发该论文重新分析。

这里实现的是数字 PDF 的区域定位与按需视觉问答。尚未接入完整扫描件 OCR、整篇公式到 LaTeX 的自动转写索引、表格 HTML 重建。连续无编号的推导可能作为一个公式组；目前也没有对两份文献的每个公式人工标注计算召回率。不能将候选统计或几个成功问答解释为全部公式均已正确识别。
