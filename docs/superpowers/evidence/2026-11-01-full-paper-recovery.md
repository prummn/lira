# 长论文全文分析恢复：SWE-smith 与 Terminal-Bench

用户报告 SWE-smith 全文智能分析失败，提示归纳遗漏事实或引用范围外证据。
本轮在原工作区修复，保留已有修改、论文和手工知识决定。

## 实际原因

原任务 `task-fff85bed4bee420e9a2daa6bc1cff350` 已处理全部 154,047 个原文字符，
46 页、1,125 个原文块、10 个抽取窗口。失败发生在递归归纳的第三层；抽取阶段
另有 3 个未知 source_id。归纳中的父事实 ID、证据 ID 和父级证据交集需要模型
重复维护，局部错误会触发整组纠错，六次恢复预算用完后整篇失败。

旧设计把 48,000 字符同时当成归纳分组上限和最终综合上限。只读重建 SWE-smith
九个已缓存窗口时，127 个事实、196 段证据组成的完整上下文为 126,940 字符。
这个量在有界长上下文中可直接综合，却被旧流程反复压缩；引文不可改写，压缩
正文描述的收益逐层下降，引用链负担增加。

第一次较小的修复只增加纠错后的保留父事实回退。相关 76 项回归通过，但真实
重试仍进入多层归纳，说明它没有解决预算设计。该任务通过任务取消接口停止，
保留已完成调用及缓存；没有把排队或运行中说成已成功。

## 修复

- 区分归纳组与最终综合预算：每组仍为 48,000 字符；最终事实和原文证据账本
  上限为 160,000 字符。能放下时直接综合并保留全部已验证事实，超长论文继续
  有界归纳。预算和算法版本写入结果指纹，报告记录实际大小及 direct/reduced。
- 对归纳漏项先做确定性恢复：保留可验证的压缩结果，将遗漏父事实原样传递。
  无效内容和错误引用不进入卡片；只有完整保留来源且真正缩小上下文才能继续。
  正常的目标条数是压缩目标，不能成为拒绝一个安全、较短回退的理由。
- 成功的回退保存在独立、会重验的归纳检查点；重复执行不用再为相同坏输出
  调用模型。无法压缩时仍保留阶段缓存并安全失败，不循环或悄悄丢弃晚期结果。
- 单个抽取项的未知 source_id 在原窗口中定向纠错。只允许修复指定字段，
  已接受事实保持不变；必须重新核验来源和原句。外来 ID、重复字段、未知字段、
  畸形字段均拒绝。纠错仍共用有上限的恢复预算，不支持的条目继续明确缺失。
- 完全修复的抽取窗口存为已核验检查点。最终卡片逐项证据校验、科学复核、
  原文指纹、取消保护和原有卡片保留规则继续执行。
- 最终综合只引用短证据 ID；在完整账本稍超预算时，无损省略模型不需要的
  内部 fact/chunk ID。事实正文、章节、短引文 ID 和原句全部保留，内部 ID 与
  PDF 坐标继续由后端映射。能直接放下的请求保持原样，既有综合缓存不失效。
  归纳阶段仍保留父事实 ID，不能以此跳过来源链校验。Terminal-Bench 两轮归纳
  后的账本从 174,427 缩为 149,052 字符，保留 229/229 事实，避免第三轮压缩。
- 从安全回退检查点重放时，原坏行仍会重新校验；被完整父事实回退解决的诊断
  明确标为 resolved，并记录 cached recovery，避免已完成结果展示历史未解决错误。
