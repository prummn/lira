# 手动调整后台额度保留线

用户授权在应用内手动控制保留线；默认策略保持不变，不代替用户选择新数值。复用现有额度决策、即时唤醒和持久化机制。

- 后台任务页面与阅读器预译队列均提供「调整保留线」入口。
- 共用弹窗显示官方长/短窗口剩余额度和正在编辑的保留线，三个数值可手动输入，长/短停止保留线最低 0，闲时启动阈值必须高于短窗口停止线。
- 只 PATCH 三个额度字段，在工作器互斥锁中与最新设置合并，避免覆盖连接、后台开关或其他任务参数。保存后唤醒工作器，不中断在途翻译，已完成译文保留。
- 全部官方连接共用该策略，单段手动翻译和提问不受后台保留线约束；官方额度耗尽仍不能绕过。
- 前端验证保存、刷新持久化、失败保留草稿、0 值和窄窗口；后端验证局部更新、持久化、唤醒、非法数据原子拒绝与耗尽额度拒绝。
- 完成相关回归及生产构建，在无在途模型请求时加载正式服务，通过实际页面验证设置入口；不擅自修改用户当前保留线。
