# Windows 同学试用包

目标：把当前工作区的可用版本打成 Windows x64 ZIP；解压后双击启动，不要求安装 Python、Node 或 npm。

采用 Python 官方嵌入式运行环境、当前已验证的后端依赖和已编译前端，由同一个本地 HTTP 服务提供界面与 API。附带官方 Codex 原生程序，账户仍由每位使用者在设置中自行登录。源码和第三方许可随包提供。

用户数据固定存于 `%LOCALAPPDATA%\LIRA`，与安装目录分离；可通过启动器参数指定隔离测试目录。只监听 127.0.0.1。已有健康实例重复启动复用；被占用的端口自动避让；停止通过实例专属令牌请求优雅退出，不按端口强杀程序。

打包仅从后端源码、迁移、提示词、前端构建/源码、专用启动器和运行环境清单复制。禁止复制任何开发数据库、PDF、聊天、缓存、日志、模型设置、账户文件或 `.env`。产物清单带 SHA256，检查凭证和文件边界。
