# LIRA 阅读体验实施计划

Goal: 连续读 PDF，以结论和原句的双向对应组织笔记本，统一 LIRA 视觉。

Architecture: PdfViewer 管文档和滚动，各页组件独立渲染/命中坐标；EvidenceSources/证据索引组件复用 ScientificText；品牌使用代码原生 SVG。无后端数据库变化。

- [x] PDF：先建立滚轮跨页与定位回归，实施可见页虚拟渲染、当前页识别、缩放锚点和懒加载。
- [x] 来源：建立大量/重复/缺失引用的回归，抽取来源分组工具和可展开原文组件；卡片每条结论只显示一个入口。
- [x] 证据：按确切位置去重，章节筛选，显示关联总结并可返回具体卡片条目。
- [x] 笔记本：统一衬线正文、KaTeX、紧凑状态区与章节层级，保留笔记输入与报告。
- [x] 品牌：LIRA wordmark、定制矢量标志、favicon、标题、README 与集中视觉样式。
- [x] 验证：真实长论文现场检查、深浅主题与窄屏，代码审查，完整前端回归与生产构建，提交实现。
