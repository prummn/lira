# 全局后台任务监视

**Goal:** 离开阅读器后仍能查看、控制翻译队列，并保留最近完成记录。

**Design:** 左侧常驻「后台任务」打开独立页面；监视页不报告阅读状态。按论文显示任务名称、完成段数、进度与等待原因，提供暂停/继续/取消/重试和打开论文。所有活动翻译与最近十条终态通过现有 status API 返回精简摘要，不在轮询传译文。保留原有专题研究入口；官方额度与更新时间可在监视页直接查看。关闭服务仍停止执行。

**Scope:** 复用现有调度、权限与操作 API，不新增自动翻译授权，不改用户额度设置。沿用现有暖色界面，以列表和细进度条呈现。
