# 导入分析任务进入后台监视器

目标：导入后或手动提交的论文分析，立即可在后台任务中找到，显示真实阶段和进度；完成、部分完成、失败与取消均能区分。

- [x] 用实际 PDF 导入接口复现：勾选分析后，后台状态包含排队任务；推进状态后同一条任务反映进度，不携带完整分析报告。
- [x] 后端提供独立、轻量的 `analysis_tasks` 摘要：所有活跃任务不受历史数量限制；最近记录仅保留每篇最新一次分析，最多十篇。
- [x] 后台列表与侧栏纳入分析；阶段、错误与进度清楚显示；支持已有取消/重试接口与打开论文，操作同步文献库状态。进入页面立即刷新。
- [x] 浏览器验证等待到完成、未知总步数、失败/部分完成、取消与重试、跳转、刷新与窄屏；保留翻译队列回归。
- [x] 运行后端相关回归、浏览器回归、构建与 diff 检查；通过旧服务兼容显示安全更新当前前端，未重启或中断用户进行中的分析。轻量汇总接口下次正常启动生效。
