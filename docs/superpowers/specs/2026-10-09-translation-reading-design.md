# 论文对照阅读

## 目标

读者始终面对原始 PDF：英文、公式、图表和分页保持原版排版。中文是随当前段落打开的阅读旁注，默认位于右侧，可以移到底部。切换模式不重新打开 PDF，也不自动翻译全文。

## 阅读交互

- 阅读器保留「原文」「中英对照」两个入口。对照模式暂时隐藏笔记本，返回原文后恢复笔记与问题的编辑状态。
- 鼠标移到自然段时出现细边框、轻微阴影和「翻译此段」浮框。浮框不挡住文字选择。同一段包含多个来源区域时，操作跟随实际悬停区域。
- 点击才请求翻译。当前段单独显示等待、错误和重试，仍可翻页和选择其他段落。旧请求返回后不会覆盖当前段的内容。
- 已保存的译文显示「展开译文」，再次打开不调用模型。关闭旁注保留译文；缓存按完整原文、服务配置和翻译提示词区分。
- 旁注支持前一段、后一段、展开原文对照。未选择段落时列出当前页段落，可用键盘或触屏操作；选段本身不会发起翻译。
- 右侧与底部的位置偏好保存在浏览器。阅读区不足 1040px 时自动改用底部，扩大后恢复偏好，避免压缩原文。
- 阅读工具栏提供「收起侧栏，专注阅读」，退出时恢复导航。应用导航和 PDF 页码工具栏保持紧凑，滚动留在各自面板内。

## 段落与数据

从已有原文块和 PDF 行布局派生段落，不更换原文块 ID、证据、笔记或 PDF。完全匹配原文的行才用于拆分和细化坐标；部分匹配只用于阅读顺序和字体分类。根据缩进、行距和句末边界拆分段落，只在明确连续的断句跨块或跨页时合并。短公式片段依照版面位置保留，并与引入它的正文或相邻公式片段一起展示。

`GET /api/papers/{id}/reading-paragraphs` 返回段落、原文锚点和匹配缓存。原翻译接口增加可选 `paragraph_id`，仍兼容 `chunk_id`。译文继续保存到已有 Translation 表，无需数据库迁移。

## 排版与边界

中文正文使用高对比衬线字体，默认 17px、两倍行距；窄屏最小 16px。`ScientificText` 使用本地 KaTeX 渲染明确标记的行内及独立公式，保留引用编号。普通文本不会解释为 HTML，KaTeX 禁用受信任命令并限制展开与尺寸。

PDF 不是 TeX 源文件。不能准确提取的公式保留来源文本，模型不得根据常识补全；原版 PDF 用于核对。无模型时可读原文和已有缓存，新译文需先在设置中配置模型。

## 验证

后端验证自然段拆分、跨页续句、图注后的续句、短公式、重叠数学文本块的排序，以及确切原文与配置匹配的缓存。浏览器验证原版 PDF 常驻、悬停操作、显式请求、收起与缓存重开、公式和文本安全、局部错误、翻页、多锚点悬停和窄屏布局。另用 Attention Is All You Need 验证真实模型翻译与宽屏、窄屏的实际阅读效果。
