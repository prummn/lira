# 论文对照翻译阅读设计

## 目标

把当前的“段落卡片 + 常驻按钮”改成适合长时间阅读的对照阅读面板。英文原文始终是主内容，译文是按段落按需展开的第二层信息；用户可以在不离开阅读流的情况下翻译、收起译文、定位回 PDF，并在下方或右侧查看译文。

## 交互

- 阅读模式保留原始 PDF、对照阅读和中文阅读三个入口；对照阅读作为默认的翻译工作区。
- 对照阅读连续展示原文块，不再把每个块做成厚重的独立卡片。段落之间用呼吸感和细分隔线区分，章节变化使用轻量的章节眉标。
- 鼠标悬停或键盘聚焦段落时，段落右上角出现带阴影的浮动操作条，包含“翻译此段”和“定位原文”。操作条不占正文空间，触屏设备上保持可见但低对比。
- 译文只在当前段落内展开，默认位于英文下方；工具栏提供“下方 / 并排”布局切换，切换只影响当前阅读会话并保存在本地。
- 已缓存译文再次打开直接展示，不重复调用接口。翻译中只锁定当前段，其他段落仍可阅读和定位。
- 译文保留换行、公式、引用编号、缩写和方法名。UI 不把译文塞进普通按钮或灰色提示；译文使用稍小但高对比的中文排版，与英文建立清晰层级。
- 没有模型时仍显示原文；当前段只显示明确的配置提示，不把提示复制到每个段落造成噪声。

## 数据与组件

- 沿用现有 `PaperDetail.chunks` 和 `translations`，不改变数据库结构和缓存键。
- `ReaderPage` 负责翻译状态、当前展开段、布局偏好和错误状态。
- 新增轻量 `TranslationParagraph` 组件负责段落呈现、悬停操作、译文展开和定位回调，避免把交互继续堆在 `ReaderPage` 的单行 JSX 中。
- 文本展示使用保留空白和换行的 text 节点；不执行论文内容中的 HTML。公式和 TeX 片段按原样显示，避免翻译过程破坏符号。

## 视觉方向

- 主阅读流使用窄幅、偏暖的纸张背景和明确的英文正文色；段落悬停采用细边框、柔和阴影和左侧色标，操作条像编辑器浮层而不是卡片按钮。
- 英文使用较大的行距与适中的字宽；译文用独立的淡色底和左侧细线，避免与背景融在一起。
- 章节信息只在章节首次出现时显示，页码和“定位原文”退到辅助层，减少机械重复。
- 对照并排模式只在足够宽的阅读区启用双列，窄屏自动回退到上下布局。

## 验证

- 前端回归覆盖：原文始终可见、悬停/聚焦操作条可见、点击翻译只发起一次请求、译文显示和收起、下方/并排切换、缓存译文不发请求、没有模型时原文仍可读。
- 继续运行现有前端全量 E2E、后端全量测试和生产构建。
- 使用真实论文的长段落检查滚动、章节切换、公式/引用字符和 PDF 定位。
