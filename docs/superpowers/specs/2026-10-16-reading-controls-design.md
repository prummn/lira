# 阅读控制与词典速译设计

## 目标

让论文阅读中的三个高频动作更接近真实使用习惯：选中一个短词即可快速查词；保存高亮后，辅助气泡不能覆盖正文；笔记列表能按类型筛选、用颜色快速识别，并可在文中顺序与最近修改之间切换。

## 交互约定

短词速译只在选区为 1–4 个英文词、长度不超过 80 个字符且不含长句标点时出现。入口位于现有选区操作条，显示“词典速译”，结果包含词性、中文释义、音标/读音（词典提供时）和例句；查询先走后端词典服务并按规范化词缓存，失败时保留原选区并说明词典暂不可用，不调用全文模型。段落翻译仍使用原有“翻译此段”。

高亮和笔记的 PDF 标记保留原有精确几何。笔记 marker 默认贴在页面内侧边缘，和正文保持固定间距；靠近边缘时选择另一侧，页面太窄时只显示小 marker，点击仍打开对应笔记。marker 不改变原文布局，也不拦截正文选取。

笔记列表默认按第一个有效 anchor 的页码、纵坐标和横坐标排序，缺少 anchor 的旧笔记按创建时间排在后面。同一位置按创建时间稳定排序。用户可以切换为“最近修改”，按 updated_at 降序。类型筛选默认“全部”，选择 highlight、todo、question、idea、note 后只显示该类；类型徽标和 PDF marker 使用同一组颜色变量。

## 边界与回退

词典请求使用固定公开词典域名、短超时、大小上限和内存缓存；词条不存在、网络失败和响应格式异常都返回安全的可展示错误，不把上游内容写入日志。筛选和排序只影响当前笔记视图，不改变数据库顺序、锚点或引用关系。旧笔记没有 anchors 时仍可编辑、删除和按时间显示。

## 验证

后端覆盖词典词条解析、缓存命中、超时/不存在、上游内容限制；前端覆盖短词入口不触发段落翻译、词典结果展示、marker 避让、类型筛选和两种排序。使用真实阅读页检查 marker 不覆盖 PDF 文字，运行完整后端与浏览器回归。
