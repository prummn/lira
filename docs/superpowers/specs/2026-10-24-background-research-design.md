# 专题文章与后台研究

已确认：在 LIRA 运行期间，将用户划定的专题作为研究范围，使用指定的官方 Codex 连接闲时推进一篇持续更新的文章。文章提出和回答跨论文问题，保留论证、适用边界与原文出处，而不是逐篇摘要拼接。每次发布保留版本，失败或被阅读打断不能覆盖上一版。

第一版闭环：专题启用与研究方向 → 材料指纹去重 → 原文研读/论证提纲 → 写作 → 原文引用与论证审读 → 发布。步骤独立持久化；每轮有限调用，无变化则休息。先覆盖专题文章，后续研究任务用同一持久化队列扩展，不引入无穷自我派单。

后台只使用显式选择的 Codex 订阅连接，不修改当前阅读连接，不使用付费 API 备用路由。按官方返回的实际限额桶和窗口判断，默认启动剩余 >50%，停止 <=35%，长窗口保留30%，未知/过期额度暂停。每轮限制调用数，每次调用前重新检查。额度不是 token 的线性换算；取消不保证退还额度。

阅读页面活跃时、翻译或提问请求到来时，取消后台正在运行的子进程并让出共享账户通道。已完成的步骤保留，未完成步骤下次重做。关闭服务、停用专题和任务取消同样遵守边界。

界面：专题中“文献 / 专题文章”自然切换；暖色纸面、衬线标题、舒适正文、简短运行状态。文章使用轻量编号引文，可展开原文并打开 PDF。研究方向、任务进展、额度策略、版本历史放入侧栏/设置浮层，避免仪表盘压过正文。支持深浅色、窄屏、键盘、导出 Markdown。
