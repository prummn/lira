# 阅读驱动的后台研究

这轮把后台从一次性整理积压改为日常阅读的延续。保留单并发、阅读抢占、证据核验、不可变历史和有限议程。

1. 专题新增可选任务「跟进阅读疑问」。问题笔记、未完成的论文/选段提问按原始身份与内容进入有限队列；成功回答不自动重答。它们产出独立的「阅读疑问」解释，个人困惑不能被描述为领域未知。取消不会自动复活。修改、删除、范围变化和后续成功回答在调用前后检查。
2. 阅读疑问不依赖基础整理完成，也不使其他任务失效。先完成已有核验步骤，再优先处理阅读问题。阅读问题及纯高亮不再触发整轮专题重写；保留普通研究笔记对专题文章的更新作用，并兼容已有任务快照。
3. 研读先提供选段及相邻上下文、相关章节、仍匹配原文的既有证据，附完整章节目录与真实覆盖。必要时模型可请求一次有界扩读，再进入核验；历史解释仅作线索。已完成的旧任务不因取材策略更新而重跑。
4. 周预算按官方长窗口剩余量和距离重置天数分配。每天首次观测建立基线，账号用量增长消耗当天后台空间（包含其他客户端，不能精确归因）。预算独立持久化；重启、开关、换同账号配置不重置。短窗口阈值与长窗口保留线仍生效，前台不受后台预算限制。无长窗口则沿用短窗口策略。
5. 界面沿用现有研究列表：显示阅读来源、回到原段落、结果和取消。设置展示简单的今日预算、下次恢复时间与口径；不增加独立仪表盘。

验证：意图去重/修改/删除/恢复、成功回答抑制、调用中用户变化、预算跨天/重启/重置/多窗口、前台抢占和共享调用上限，迁移与真实库成品核验，桌面及窄屏导航。
