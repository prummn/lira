# 使用指南

## 启动工作台

在 `D:\paper_reader` 的 PowerShell 中运行：

```powershell
.\scripts\start.ps1 -InstallDependencies
```

首次运行会准备依赖并打开本地页面。以后可运行 `.\scripts\start.ps1`；用 `.\scripts\stop.ps1` 停止服务，论文和笔记会保留。详细环境要求见项目 README。

## 页面怎么分工

- **文献库**：导入、筛选和查看每篇论文的真实处理状态；选中一行后再看元数据和下一步动作。
- **阅读器**：左侧读 PDF，右侧查看卡片、证据、问答和笔记；所有引用都能回到原文。
- **AI 文献员**：限定资料范围后跨论文提问；回答会分开标记论文事实、个人笔记和模型推断。
- **领域知识**：查看集合时间线、已记录关系、论文比较和概念索引。
- **研究者**：从作者反查论文和共同署名，不补造机构或任职信息。
- **设置**：查看当前真实生效的模型、主题、语言和数据位置；不保存 API key。

页面中的主要动作都直接写出下一步，例如「打开阅读器」「查看原文」「重试分析」。分析状态和阅读状态互相独立；「仅原文」表示论文可以正常阅读和检索，不是错误。

## 从一篇 PDF 开始

进入「文献库」，点击「导入 PDF」选择文件，或把 PDF 拖入页面。可以批量选择；每份文件会有独立结果。当前上限为 50 MB，相同内容重复导入会提示已有，损坏文件不会加入 Library。

选择或拖入文件后，先确认本批文件与「导入后智能分析」选项。首次默认不勾选，之后记住本机浏览器的偏好，每批可更改；没有配置远端模型时禁用。确认不分析也会正常保存 PDF 并生成本地摘录，列表显示「未进行智能分析」。勾选后先完成本地导入，再顺序执行远端任务，无需等任务结束才能阅读。

点击论文标题进入「正在阅读」。左侧是原始 PDF，可用页码、目录、缩放和全文查找；右侧是阅读 Notebook。阅读页码会保存，重新打开可继续上次位置。列表中可修改阅读状态、收藏、标签和所属集合，这些更改保存在本地。

标有 DEMO 的论文与作者是虚构研究样本，用于体验流程。扫描 PDF 可阅读和记录笔记，但没有文本层时无法自动分析；本版本没有 OCR。

## 通过链接导入

在文献库点击「链接导入」，粘贴 `https://arxiv.org/abs/1706.03762`、arXiv PDF 地址或可公开访问的 PDF 直链，然后点击「下载并导入」。下载和识别期间有状态提示；失败时保留输入并显示原因，可以修正链接后重试。HTML 论文介绍页不能当作 PDF 直链，纯 DOI 编号和 Zotero 导入尚未提供。

完成后可直接打开论文。在一个集合内导入时会加入该集合；如果 PDF 已保存但加入集合失败，页面会显示「论文已保存」和「重试加入集合」，重试只处理归属，不再次下载。每份 PDF 最多 50 MB，相同内容仍按哈希去重。

链接导入也有「导入后智能分析」选项，与文件批次共享当前浏览器偏好。默认不开启远端分析；仅确认下载不等于授权模型生成。

## 核对与修正论文信息

点击列表行的信息图标，或阅读器顶部「论文信息」。可编辑标题、作者（每行一位，保持署名顺序）、年份、期刊/会议、DOI 和 arXiv 编号；每个字段下方显示 PDF 排版、文档属性、arXiv、Crossref 或手动修正等来源。

导入及「重新识别」先读取本地 PDF 首页版式，再按识别出的 arXiv/DOI 编号查询书目。arXiv 年份采用首次提交年份，不使用当前 PDF 修订日期。没有识别出作者、年份或 venue 时保留未知；网络不可用会保留本地结果并显示警告。下载和书目查询会访问论文来源，但不会调用模型或向模型上传正文。

「保存」只提交实际修改的字段；已保存的手动修正及手动清空的编号在重新识别时保留。尚未保存的编辑会先提示确认，再重新识别；接口失败会保留当前编辑。刷新元数据不会替换原始 PDF、现有原文块 ID、笔记、集合、收藏或阅读状态。若需重新生成论文卡片，可另行点击「分析论文」；配置模型后的分析属于主动模型请求。

## 读结论，也读来源

Notebook 的「论文卡片」提供快速概览、结构化摘要和章节摘要。点击条目旁的「定位原文」，PDF 会切换到对应页并标出原文区域。「原文证据」可查看完整引用片段。

本地 MockProvider 提供原文摘录，列表和阅读器明确标「未进行智能分析」；中英文模型摘要与推断需要有效模型。完整卡片未识别字段会留空，这不表示论文一定没有该内容。「模型总结」是 AI 写作，「个人判断」是你写的内容；引用核对只确认原句出现在文件中，解释是否成立仍需结合上下文复核。

打开「问论文」，输入问题并点击「提问」，或按 `Ctrl/Cmd + Enter`。答案引用旁的页码可回到原文；当前材料不能支持的问题会明确拒答。

## 管理智能分析任务

在 Library 勾选真实论文后可批量启动分析，或打开论文，在 Notebook 的「全文智能分析」中点击「开始智能分析」。AI 状态独立于未读／精读等阅读状态，依次显示未分析、等待、运行、完成、部分完成、失败或取消。

任务先按窗口处理已解析全文，再从可核验事实归纳卡片。进度显示阶段与步骤；长论文可能增加归纳步骤，期间仍可阅读 PDF、定位旧卡片出处和记录笔记。成功后查看「分析报告」中的处理窗口／字符、已匹配引文、接受字段、缺失字段、调用次数、缓存命中及服务报告的 token usage。未报告 usage 时显示未知，不把估算当作账单。

失败会显示原因并保留原有卡片，可「重试分析」；部分完成可能有被排除的无效条目，应检查报告及空字段。任务和阶段缓存存入 SQLite，后端重启后恢复尚未完成的任务；模型配置需在新进程仍然有效。相同论文、模型、提示词和请求可以复用成功阶段；「重新分析全文」重新建立任务，也可能全部命中缓存。

「取消任务」在模型请求之间生效。已经发出的 HTTP 请求可能继续运行并产生费用，返回后不会用已取消任务覆盖卡片。任务完成只表示本轮处理结束，不证明所有图表内容都被识别、全部字段有证据或 AI 论断语义正确。

## 与 AI 文献员对话

侧栏「AI 文献员」需要远端模型。选择全库、集合或指定论文，再输入问题；可询问多篇论文的方法差异、实验支持、书目信息或自己笔记中的研究问题。全库默认使用真实论文，未分析论文也可检索原文。大量资料时优先缩小到专题集合或明确论文，本轮检索有候选与文本预算。

每轮用模型整理中文／英文检索词，然后在本地检索书目、正文、卡片和笔记；回答按事实、比较、推断、个人笔记和元数据区分来源。论文方法／结果结论必须有原文引用，笔记引用是个人判断，书目记录无需伪造 PDF 页码。点击原文来源打开对应论文和区域，点击元数据来源查看论文信息；「返回文献员」继续当前对话。

文献员只读研究资料，不自动改书目、notes 或集合，也没有任意 SQL、shell 或外部搜索工具。缓存可能保存模型结果，但不会把回答自动写成你的研究笔记。检索受当前范围与预算限制，“本库没有找到”不能当作全球不存在；不完整比较会提示缺少候选论文证据。请核对回答下方限制和原文，原句匹配不自动证明比较或推断成立。

切换范围开始新的对话，避免沿用上一个范围的证据。对话留在当前页面会话，打开原文后可返回继续；刷新页面后不会恢复聊天记录。仅发送有限的最近对话，每轮重新检索。遇到服务错误可重试；「停止回复」停止当前浏览器等待，不保证取消已发出的模型请求或免除费用。

## 保存笔记与高亮

选中 PDF 中的文字后，点击「保存高亮」，或点击「引用到笔记」。在「我的笔记」选择阅读笔记、研究想法、问题或待办，填写内容并保存。未选中文字也可以给当前页写笔记。

笔记与高亮都标为个人判断。刷新后重新打开论文，在「我的笔记」点击页码即可回到保存的位置；删除按钮用于移除单条记录。

选中同一段落内的文字，还可点击「解释所选」，选择技术解释、直观理解、数学解释或前置知识。无模型时仅显示相关原文；跨多个段落且无法关联原文块的选区会提示重新选择。

## 围绕问题建立集合

点击「新建集合」，输入名称与描述。在论文列表的集合按钮中勾选所属集合，或使用 Notebook 顶部的集合管理按钮。一个论文可属于多个集合。

选择集合后进入「领域知识」：

- 「技术时间线」按年份和论文内容浏览；没有已核实关系时会明确说明。
- 「引用与方法关系」只显示已经记录的边；示例关系与 AI 推断有来源标记。相似主题不会自动成为引用或继承关系。
- 「论文比较」勾选 2–4 篇论文，比较问题、方法、结果和局限；查看原文按钮可回到论文核对。空字段表示尚未识别。
- 「概念索引」按论文卡片中的术语找到相关论文；这是术语索引，不是已确认的方法谱系。

「研究者」根据当前 Library 的作者和共同署名展示关联论文；没有核实的机构或任职关系不会补造。

## 搜回以前读过的内容

在文献库搜索框输入至少两个字符。列表匹配标题、作者、venue 和标签，下方「正文中的匹配片段」来自本地 FTS 全文索引。点击正文结果可以直接打开相应论文和原文页。选中集合后，搜索限定在该集合内。

PDF 工具栏的全文搜索只查当前 PDF；文献库搜索查本地 Library。当前不提供 embedding 语义搜索。`Ctrl/Cmd + K` 可回到文献库搜索。

## 配置模型后，主动执行操作

未配置模型也能导入、阅读、摘录、记录笔记和查看关系。需要智能分析、AI 文献员、模型解释或新的逐段中文翻译时，首次配置可复制 `.env.example` 为项目根目录的 `.env`，填写：

```dotenv
PAPER_READER_MODEL_BASE_URL=https://你的服务地址/v1
PAPER_READER_MODEL_NAME=你的模型名称
PAPER_READER_MODEL_API_KEY=你的key
PAPER_READER_MODEL_WIRE_API=chat_completions
PAPER_READER_MODEL_REASONING_EFFORT=disabled
PAPER_READER_MODEL_TIMEOUT=600
```

模型请求超时默认为 600 秒，允许范围为 1–1800 秒；长篇 Responses 合成可按需使用更长时限。

支持 Chat Completions 或 Responses 协议，内容需能返回有效 JSON。已确认的 SpacetimeAI profile 为 `PAPER_READER_MODEL_BASE_URL=https://spacetimeai.cc`、`PAPER_READER_MODEL_NAME=gpt-6.1-sol`、`PAPER_READER_MODEL_WIRE_API=responses`、`PAPER_READER_MODEL_REASONING_EFFORT=xhigh`；长篇分析建议 `PAPER_READER_MODEL_TIMEOUT=600`。Key 由你在环境变量或被 Git 忽略的 `.env` 中提供，示例不含真实凭证。Responses 采用流式传输并使用 `store: false`，连接结束或被截断的片段不会发布为完成结果。

普通模型默认使用 `PAPER_READER_MODEL_REASONING_EFFORT=disabled`，省略推理参数并覆盖分析阶段的 effort；支持推理的模型可显式配置 high/xhigh 等值。`none` 是发给服务的实际 effort 值，不能用于省略参数。部分 Chat Completions 服务需 `PAPER_READER_MODEL_COMPLETION_PARAMETER=max_tokens`；不接受 JSON mode 时可设 `PAPER_READER_MODEL_JSON_MODE=none`，应用仍会校验返回 JSON 和原文引用。修改后停止并重新启动工作台，在「设置 → 分析与模型」查看 Provider、协议及 reasoning effort；显示“已配置”只是配置状态，不等于真实连接或模型质量验收通过。设置页只读，不保存 key。

推荐使用应用专用的 `PAPER_READER_MODEL_API_KEY`。如果用 `OPENAI_API_KEY` 作为备用 key，必须同时显式设置本应用的模型地址或名称至少一项；应用专用 key 优先。宿主环境里单独存在通用 key 不会启用远端，工作台仍保持本地摘录模式。

若 key 仅供当前运行进程使用，应用不会把它写回 `.env`、浏览器或数据库。关闭后端后，下次启动需重新提供进程环境，或由你设置 `.env`／用户环境变量；已有 live 会话不代表重启后仍有模型配置。现有进程环境变量优先于 `.env`。

导入 PDF 固定先本地解析；没有勾选「导入后智能分析」就不调用模型。勾选该批分析、主动启动单篇／批量分析、单篇提问、AI 文献员、解释或逐段翻译时，才发送对应原文、元数据或当前范围笔记到所配置模型。书目补全和链接下载另行访问来源服务。模型错误会显示出来，原始 PDF、笔记和已有结果保留。

逐段译文会长期保存在本地 SQLite；刷新或重启后可以继续阅读。之后未配置模型时，也可切换「中英对照/仅中文」查看已缓存段落，未缓存段落仍需配置有效模型后主动翻译。原文、模型地址或翻译 prompt 改变时，过期结果不会作为当前缓存复用。

本版本的真实服务调用、缓存、引用检查和人工复核范围以 [智能分析验证](intelligence-validation.md) 为准。模拟传输检查用于验证契约；有限现场样本也不代表所有模型、长论文、解释和译文质量均已验收。

## 外观与数据

「设置 → 界面外观」可以选择浅色、深色、跟随系统，以及简体中文/English；选择保存在当前浏览器。

默认 SQLite 是 `D:\paper_reader\backend\paper_reader.db`，PDF 在 `D:\paper_reader\backend\storage`。配置覆盖路径后以实际配置为准。备份时先停止服务，再复制数据库、同名的 `-wal`/`-shm` 文件（若存在）及 PDF 目录。「导出 JSON」导出元数据，不包含原始 PDF，也不代替完整备份。
