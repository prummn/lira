# 使用指南

[文档目录](README.md) &nbsp;|&nbsp; [知识摄取](KNOWLEDGE.md) &nbsp;|&nbsp; [工作流与排错](WORKFLOWS.md)

LIRA 的日常路径是：把论文加入专题，读原文并记录问题，再利用已有材料做比较与整理。全文分析和阅读状态彼此独立，未分析的论文也能正常阅读。

## 1. 准备工作台

在仓库根目录运行 `.\scripts\start.ps1`，或双击「启动工作台.cmd」。浏览器会打开实际服务地址；首次运行需要准备依赖。停止时运行 `.\scripts\stop.ps1` 或「停止工作台.cmd」。

只阅读、搜索和记笔记，无需配置模型。要使用翻译、问答与智能整理，先到「设置 → 模型连接」添加连接，详见 [模型连接](MODELS.md)。

## 2. 把论文放进来

在文献库选择 PDF、拖入文件，或用「链接导入」粘贴 arXiv 页面、arXiv PDF 或公开 PDF 直链。每份文件上限为 50 MB；重复文件会提示已有记录。

导入前可以按批选择：

| 选择 | 后续行为 |
| --- | --- |
| 只导入原文 | 保存 PDF，解析文本与位置，准备本地阅读和检索 |
| 预译正文并后台分析 | 先准备阅读与正文预译，再推进全文分析；无需等待全部完成 |

书目信息会结合 PDF、arXiv / DOI 信息补全。可在「论文信息」中修正标题、作者、年份等；重新识别会保留已保存的人工修正。无法确认的字段保持未知。

已有论文可以通过「加入集合」调整专题归属，也支持多选后批量加入。一篇论文可以属于多个专题，从专题移除不会删除论文和笔记。

## 3. 阅读与对照

点击论文标题打开阅读器。PDF 连续滚动，目录、页码和全文查找可以跳到目标位置。阅读位置自动保存。

切换「中英对照」，将鼠标移到段落上，再选择翻译或展开已有译文。中文旁注可以放在右侧或下方；切页时保留当前译文，方便跨页阅读。译文中的公式使用 KaTeX 排版，遇到复杂公式仍应结合 PDF 核对。

「批量翻译」可以选择多段加入队列，完成的段落立即可读。重要论文可以启动「后台预译全文」，默认预译正文与图表说明，遇到附录或参考文献停止。离开阅读器后，在「后台任务」查看完成段数和等待原因。暂停与重启保留已完成结果，失败项可重试。

## 4. 在上下文中提问

划选 PDF 或译文中的内容，输入自然语言问题。译文提问同时带上中文选区与英文依据；已识别的图表可单独选择发问。图像输入需要模型具备视觉能力。

等待回答时，可以收起窗口继续读。阅读器顶部的「阅读对话」和历史入口能找回问题、选区、回答与引用。单篇问答、阅读对话和 AI 文献员的已提交内容保存在本机；「新对话」保留旧记录。

本地服务必须继续运行才能完成请求。重启导致中断时，历史会保留问题和未完成状态，可由你选择重试。

## 5. 保存高亮和笔记

只做标记时，划选后「保存高亮」即可。需要写想法时，选择「引用到笔记」，或在「我的笔记」中写阅读记录、研究想法、问题或待办。笔记可以保留原文、页码与定位信息，点击来源可回到 PDF。

笔记支持修改、删除和公式排版。标记保存在本地数据库，不会写入下载的原始 PDF。

## 6. 看分析，也看依据

论文卡片整理问题、方法、结果和局限。展开「查看依据」，可以读原句、查看章节与页码，再定位到原文。字段为空可能表示尚未识别，不能据此断定论文没有相关内容。

分析中、部分完成和失败会分别展示。已有 PDF、笔记和可用结果保留；失败后查看具体原因并重试，不必重新导入同一份论文。

## 7. 从论文走向专题

在「知识摄取」中选择专题，浏览技术时间线、关系图、方法演进、论文比较与对象目录。打开对象档案可以查看别名、相关论文、已记录链接和证据。希望减少逐条处理时，在「AI 知识整理」发起当前范围整理，或开启后台自动整理。

更详细的对象与关系说明见 [知识摄取与网络整理](KNOWLEDGE.md)。专题文章、研究线索和复习任务的开启方法见 [后台任务与调度](BACKGROUND_TASKS.md)。

## 8. 跨论文查找

AI 文献员支持全库、集合和指定论文三个范围。先圈定材料，再问具体问题；回答可以引用原文、个人笔记与书目信息。引用可展开并定位来源，对话历史可继续使用。

文献库的搜索用于查标题、作者、标签和本地正文，PDF 工具栏只搜索当前文档。当前没有 embedding 语义搜索。每日研究热力图记录阅读、笔记等活动，点击日期可查看相关论文；颜色不代表研究质量。

## 数据与备份

「设置」中可查看实际数据位置。开发版默认使用 `backend/paper_reader.db` 与 `backend/storage/`；独立应用包使用 `%LOCALAPPDATA%\LIRA`。停止服务后备份数据库及其同名 WAL / SHM 文件（若存在）和原始 PDF 目录。

「导出 JSON」不包含原始 PDF，不能替代完整备份。连接配置与登录状态另外保存，包含敏感信息，处理方式见 [安全与隐私](../SECURITY.md)。
