# 工作流与排错

[文档目录](README.md) &nbsp;|&nbsp; [使用指南](USER_GUIDE.md) &nbsp;|&nbsp; [模型连接](MODELS.md)

这里集中列出常用路径与状态区别。详细功能见对应指南，避免在每份文档中重复配置参数和调度规则。

## 四条常用路径

| 目标 | 路径 | 阅读说明 |
| --- | --- | --- |
| 精读一篇论文 | 导入 → 打开原文 → 中英对照 → 提问 / 笔记 | [阅读与记录](USER_GUIDE.md#3-阅读与对照) |
| 建立一个专题 | 新建集合 → 加入已有论文 → 知识摄取 → AI 知识整理 | [对象与关系](KNOWLEDGE.md) |
| 比较已有工作 | 选择专题 → 论文比较 / 方法演进 → 展开原文依据 | [浏览知识](KNOWLEDGE.md#怎样浏览已有知识) |
| 持续整理资料 | 研究设置 → 方向与任务类型 → 开启后台 → 查看结果 | [激活与监视](BACKGROUND_TASKS.md) |

## 状态不是同一个维度

| 看到的状态 | 实际表达的事 |
| --- | --- |
| 未读 / 阅读中 / 已读 | 个人阅读进度 |
| 未进行智能分析 | 已有本地原文，尚无远端全文分析结果 |
| 分析排队 / 运行 / 部分完成 / 失败 | 全文分析任务当前进度 |
| 预译完成段数 | 当前翻译任务已经保存的段落数量 |
| 已检查论文 | 本轮 AI 知识整理已经核对过的论文 |
| 待确认对象 / 关系 | 仍需处理的知识条目，不等同于未检查论文数 |

一篇论文可以读完了但尚未分析，也可以分析失败但知识整理已有结果。判断是否需要重试，应查看对应任务的原因与覆盖情况。

## 恢复操作

| 问题 | 建议操作 |
| --- | --- |
| 服务未启动或地址不对 | 重新运行启动脚本，使用脚本打开的实际地址，查看 `.local-runtime/` 日志 |
| 链接下载失败 | 检查是否为支持的 arXiv / 公开 PDF 地址，以及来源站点可用性 |
| 论文信息缺失 | 打开论文信息重新识别，或手动修正；保留原 PDF 和笔记 |
| 翻译未完成 | 查看对应段落或后台队列，重试失败项，无需重新翻译已完成段落 |
| 分析部分完成或失败 | 查看具体服务 / 校验错误，再重试分析，保留原文和已有结果 |
| 提问窗口找不到 | 在阅读对话或历史记录中选择本篇论文的对话 |
| 方法或对象重复 | 先发起 AI 知识整理，再从对象档案检查别名、类型和来源 |
| 后台长时间等待 | 查看连接、额度读取、保留线、预算与空闲条件 |

模型故障的检查见 [模型连接](MODELS.md#常见情况)。自动整理的边界见 [知识摄取](KNOWLEDGE.md#ai-整理怎样减少手工工作)。

## 反馈问题时保留什么

记录操作路径、论文标题或脱敏样本、发生页码、任务状态和错误信息。版面问题附能看清段落或图表边界的截图；队列问题附等待原因及时间。不要提交个人数据库、完整配置或账户令牌，详见 [安全与隐私](../SECURITY.md)。
