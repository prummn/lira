# 阅读高亮与笔记验证

2026-10-15。本次修复覆盖 PDF 原文、关联笔记及持久存储，不调用模型。

## 原因与修复

原来的「保存高亮」只写入笔记表，PDF 阅读器没有接收或绘制笔记；「引用到笔记」只切换标签，没有建立引用草稿或定位编辑器。旧测试只检查笔记列表，漏掉了 PDF 原文显示。

现在保存每页尺寸和逐行区域，缩放时通过 PDF 坐标转换恢复标记。跨页引用共用一个笔记；正文点击及页边按钮可打开关联笔记，笔记页码可返回原文。同段相同来源合并页边入口。旧的 page/bbox 笔记尝试从文本层恢复准确选区，无法匹配时保留原坐标标记。

引用草稿持有独立的来源快照。笔记修改仅更新内容和类型，保持 ID、原文和位置；高亮可补写想法。删除成功后同步移除关联，失败保留笔记和标记。切换标签保留草稿，切换引用时提供继续编辑、保存后切换、放弃草稿三个路径。
