## 分段与数学原文

真实论文检查发现并修复了短公式被过滤、重叠上标文本块排到页末、多区域段落浮框出现在错误区域的问题。公式片段现在保留确切来源，同行的相邻片段按原版左右位置排列；跨栏的独立公式不会合入另一栏正文。原始 PDF、证据块和笔记 ID 保持不变。

这项改动不恢复原始 TeX 源码。PDF 的分式、矩阵和特殊符号可能仍被拆成不完整文本；翻译提示词要求不确定时保留原文，原始 PDF 用于核对。模型质量结论仅覆盖上述样本。
