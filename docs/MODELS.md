# 模型连接

[文档目录](README.md) &nbsp;|&nbsp; [后台任务](BACKGROUND_TASKS.md) &nbsp;|&nbsp; [安全与隐私](../SECURITY.md)

模型通过「设置 → 模型连接」管理。每份连接独立保存地址、模型和参数；保存后立即生效，不必重启。基础阅读与已保存结果不依赖有效模型连接。

## 两种接入方式

| 方式 | 需要准备 | 适用场景 |
| --- | --- | --- |
| API key | 服务地址、模型名称、密钥与协议 | 使用官方 API 或兼容服务，可配置各连接并发 |
| ChatGPT Codex | 官方 CLI 与账户登录 | 使用账户实际提供的 Codex 模型和额度 |

API 余额与 ChatGPT 订阅中的 Codex 使用额度属于不同计量方式。是否有某个模型、是否支持图片、能承受多少并发，以服务与账号实际返回为准。

## 添加 API

1. 新建连接，起一个便于辨认的名字。
2. 填写完整 API Base URL、模型与 key，选择 Responses 或 Chat Completions。
3. 根据服务能力配置推理强度、超时和同时请求上限；不支持的参数应关闭。
4. 点击「测试连接并保存」，成功后启用这份连接。

地址应使用供应商文档中的 API 地址，避免把网站首页当接口；是否包含 `/v1` 取决于实际服务。部分兼容服务需要关闭 JSON mode，或调整 Chat 输出预算参数。测试失败不会覆盖现有配置。

编辑已有连接时，密钥留空会沿用原 key；浏览器不会得到已保存密钥的明文。模型请求仍会进行结果结构和引用检查，兼容接口并不保证所有能力都可用。

## 登录 ChatGPT Codex

源码环境需要安装 [官方 Codex CLI](https://developers.openai.com/codex/cli/)：

```powershell
npm install -g @openai/codex
```

新建「Codex 订阅」连接，点击「登录 ChatGPT」，在官方登录页完成授权。返回后刷新账户和模型，选择当前账户提供的模型与推理强度，再测试并启用。

模型选项来自 CLI 的能力目录。列表发生变化或旧型号不可用时，刷新后重新选择；「跟随官方默认」可避免将某个型号固定在配置中。账户页显示可读到的计划、额度与重置时间，读取失败会保留明确状态。

LIRA 使用独立登录目录，不修改 Codex 桌面或终端已有的登录。所有 LIRA 内的 Codex 连接共享同一官方账户、额度和本地并发上限。调用不提供项目文件或 shell 工具权限，论文内容通过受限请求传入。认证与令牌由官方 CLI 管理，见 [官方认证说明](https://developers.openai.com/codex/auth/)。

## 多连接与备用

可以保存多份连接并切换主连接，也可以设置备用顺序。默认手动切换；启用自动备用后，全文分析和 AI 文献员可在限流、短暂网络或服务故障时尝试备用连接。认证失败和参数错误会直接报告，不会靠反复切换掩盖配置问题。

翻译与即时问答使用主连接。切换影响后续请求，已经发出的生成使用原配置完成。缓存与分析报告保留实际端点、模型和协议身份，避免把不同连接的结果混记。

官方并发设置只改变本地调度上限；供应商限流仍会触发退避和自适应降速。后台研究的额度策略另见 [后台任务与调度](BACKGROUND_TASKS.md)。

## 数据保存

开发版连接默认保存在根目录的 `.env.models.json`，官方账户使用独立的 `.env.models.json.codex/`；均被 Git 忽略。原 `.env` 可作为首次迁移的初始配置，迁移后以应用内保存的连接为准，旧文件中的 key 需单独处理。

独立应用包的数据位置不同，以设置页显示为准。配置文件和登录目录含敏感信息，不应附在 issue、截图或复现包中。删除连接不会清理你另外保存的旧 `.env` 副本。

## 常见情况

| 现象 | 先检查 |
| --- | --- |
| 返回网页或 404 | API 地址及协议是否正确 |
| 认证失败 | key、账户授权与服务权限 |
| 不支持模型或参数 | 刷新模型目录，检查推理强度、JSON mode 和输出参数 |
| 当前模型不支持图片 | 换用有视觉能力的连接；文本问答与图表输入能力不同 |
| 单段能用，后台仍等待 | 额度读取、保留线、预算和后台准入条件 |
| 超时、限流或截断 | 服务状态、请求大小、超时和并发；保留已完成结果后重试 |

「已保存」只说明配置存在；「测试成功」只验证一次请求。真实长篇分析、翻译和图表问答仍受当前服务可用性影响。
